# KOLF 风格：可迁移的视觉规则

依据论文 Fig. 1、Fig. 2 与公开代码/已保存 notebook 输出整理。确切来源和视觉证据见 [sources.md](sources.md)。下列规则是风格归纳，不是 Nature 或作者的官方制图标准。

## 颜色与基础样式

- 主体白底，文字深灰；需要区分图谱区域时，可使用极浅灰底。用稳定的类别色和留白组织画面，不依赖外框或装饰。
- 普通统计图去掉上、右轴线，默认无网格；必要时保留很轻的读数辅助线。坐标含义重要时不可为了简洁隐藏坐标。
- 英文/数字优先 Arial，中文选可用的无衬线字体，缺失时选已安装字体并告知替代。不要强制下载或分发字体文件。
- 单条数量曲线使用蓝色及浅蓝填充；比较时使用有限的强调色和参考灰。多类别图可使用 Plotly Bold 色板，数据点以适度透明度降低拥挤感。
- 分类颜色表不表达高低。连续数值使用连续色板；正负变化且零点有明确意义时才使用以零为中心的发散色板。
- 参考代码的相关热图使用 `RdBu`：低值红、高值蓝。其他图若使用不同方向，应在色条写明，不能跨图悄悄反向。
- 连续色阶需要按当前数据与比较任务设定。只有需要比较的面板共享范围；不把论文热图的 ±0.5 当成所有相关图的固定范围。裁切端点要显示超出标记并在图注说明。

## 图型处理

**曲线与普通散点**：保留清楚的轴标题、单位和变换方式。重点少量突出，其余降低饱和度/透明度。阈值线必须有含义，并用简短标签解释。密集点云可采用透明度或密度显示；如抽样，说明抽样口径。

**MDE/UMAP 等嵌入图**：数据结构由算法决定，不能手动移动点。无解释价值的轴刻度可以隐藏，但保持有依据的纵横比例。可从 `s=7 pt²`、`alpha=0.7`、白边 `0.3 pt` 起步；PPT 需要按实际缩放重新调整。重要簇直接标功能或名称，其余不逐点标字。

**热图**：密集格子不画网格线；不堆满无法阅读的基因名。使用行列类别色条、关键标签或旁边的紧凑说明表。树状图是否保留由解释任务决定。色条只保留足以读懂的刻度与变量名称。

**网络图**：先画浅色连线，再画节点和标签；只有有方向含义的关系才加箭头。节点大小若编码数值，说明是面积还是半径并保持映射一致。先改善整体布局，再移动文字或添加引导线。不可为好看删掉关键边却不说明。

**柱状图、箱线图和小提琴图**：数据表达先于装饰。有重复观测时考虑叠加原始点；明确 n 的单位、误差线含义。统计星号必须有实际检验依据。只需比较分布时不强制执行额外显著性检验。

## 信息与文字

- 用简短标题说明当前面板的问题或经数据支持的结果，不使用内部函数名或生硬变量名。
- 优先就近标注核心对象，避免读者反复查找长图例。类别标签可用同色系深色，确保浅色组的文字也清楚。
- 长功能名最多拆成易读的短行。重要信息写清楚，次要方法细节移至图注，不用缩到不可读的文字塞满图内。
- 标签密度由用途决定：探索图只点出少量对象；正式图可以增加功能模块，但仍避免无差别逐点标注。
- 重叠时先调整文字位置、留白、分面或图例形式；不通过更改科学数据解决视觉冲突。
- 多面板共享含义时保持颜色、字号和标记一致。`a/b/c` 面板字母与图内标题分层，位置对齐。

## 硬要求与起始建议

数据与统计含义、稳定颜色映射、可读性和来源说明属于硬要求。具体颜色、字体、字号、点大小、线宽、版式和导出分辨率属于起始建议，由项目 TOML 与用途覆盖。

不要照搬原论文的生物学标签、簇编号、阈值、样本量或结论。正式图与原始输出的差异可以用代码实现，不假定必须使用某种后期软件。
