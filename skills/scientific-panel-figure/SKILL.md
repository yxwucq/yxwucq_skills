# 科研 Panel 绘图

## 触发方式

用户可以直接调用 `$scientific-panel-figure`，也可以用自然语言表达组图意图。结合当前上下文判断首次回应：

| 用户请求 | 首次回应 |
| --- | --- |
| “帮我做一张科研 panel 图。” | 若上下文中也缺少主题和规格，一次问清两项。 |
| “做一张 panel 图，详细展示这个数据集的批次效应。” | 主题已明确，只问希望排成几行几列。 |
| “用 2×3 组图详细展示这个数据集的批次效应。” | 直接提交 2 行 3 列的 A–F 方案，等待确认。 |

## 先确定展示主题和规格

触发时先从用户消息和已有上下文提取两项信息：要详细展示哪份数据或哪个主题，以及整图采用几行几列。两项都缺时，在同一轮询问：“这张组图想详细展示哪份数据或哪个主题？希望排成几行 × 几列（例如 2 行 × 3 列）？”只缺一项就只问该项。信息齐全时，直接在方案开头写明主题和规格。默认把 `2*3`、`2×3` 或 `2x3` 解读为 2 行 3 列；用户明确指定方向时按其约定。

## 提交逐格方案

先查看已提供的数据字段、已有结果或主题材料，明确整张图要回答的核心问题。让各面板回答互补的子问题，并安排读者从哪一格开始、如何读到关键比较或细节。面板可以是数据图，也可以是有依据的流程或结构示意。按问题选择图型，不预设固定组合。

规划数据面板时，参考[科研问题与图型选择](references/plot-selection.md)。先辨认观测单位、变量类型、配对关系和已有汇总，再选择能揭示分布、个体变化、效应大小或多变量结构等不同信息的视图。需要跨格直接比较时，优先复用同一种图型与尺度。两种画法会引导读者回答不同问题时，在该格给出一个备选，说明换图后能多看见什么。

用一张简表列出“编号与位置｜本格回答的问题｜所用数据或材料｜拟用图型、关键编码及选用理由”。理由写到数据上，例如“按受试者连线，可看出总体下降是否由少数人驱动”。默认从左到右、从上到下编号 A、B、C…。跨格面板注明覆盖范围，确保整张表与约定的行列一致。未取得数据时可以先规划，但须指出哪些面板需要哪些输入。现有材料撑不起某格时，提出有证据的替代内容或布局调整，交由用户选择。

展示完整方案后，请用户确认或按编号修改，并在此等待。确认前只做规划和必要的材料核对。用户只提出修订时，更新原方案、保留其余面板，再请其确认；用户明确表示“把 C 换成箱线图，其余照方案画”即已授权按修订稿绘制。若制作时发现输入缺失会迫使某格更换指标或改变问题，说明受影响的编号并与用户确定替代方案。

## 按确认稿成图

逐格方案确认后，按[正式科研绘图](../formal-scientific-figure/SKILL.md)成图。依据[项目配置约定](../formal-scientific-figure/references/project-config.md)查找项目正在使用的绘图 TOML，保留用户指定的样式、已登记组色及单图覆盖。新项目从[正式绘图模板](../formal-scientific-figure/assets/plot_style.toml)初始化。按用途选择 `formal_md`、`formal_ppt` 或 `formal_paper`，未指定用途时采用 `formal_md`。由绘图代码读取生效配置，整图及单独导出的面板使用同一份正式主题。默认字体、主色、强调色、参考色和密度渐变均取自该配置，随正式主题更新。

在统一布局中复用项目的绘图脚本或 notebook。按[正式图视觉规范](../formal-scientific-figure/references/visual-style.md)处理文字、坐标和标注，统一字号层级、面板字母位置与组别顺序。同一组别跨格使用同一颜色或符号；同一指标需要直接比较时对齐单位、坐标范围或色标，不同指标按各自单位清楚标轴。仅在颜色或符号含义相同时合并图例。

行列方案确定面板的顺序和邻接关系，各格的绘图区宽度按图型、数据密度、坐标纵横比和标签长度分配。例如，列少行多的热图可采用窄矩阵，色标紧邻矩阵。同行优先对齐标题基线和绘图区底边，同列选择便于比较的一侧边缘对齐；异宽面板仍可沿共同基线移动。

按最终展示尺寸查看实际导出图。逐格检查坐标。若 x、y 是可直接比较的数值，优先使用正方形绘图区，统一单位、范围、变换和刻度，对数轴采用相同底数。其他图型沿用适合数据的宽高比。若窄图与相邻面板之间仍有大片空白，在约定行列内移动面板及其标签、色标，必要时联动调整相邻列宽。复核可见边缘、基线和文字间距，宽度与移动量由当前版面决定。逐格对照确认稿，核对数据、标签、编号与位置，修复文字裁切、重叠和难辨的图例。图内仅保留必要的短标题、面板编号、轴名与单位、刻度、图例或色标，以及识别数据的简短标签。解释性文字写入图外的完整图注，按面板编号说明样本、分组、数据处理及统计口径。按[正式图交付约定](../formal-scientific-figure/references/formal-delivery.md)和所选 profile 导出整图、预览及图注，用户或项目已指定的格式优先。
