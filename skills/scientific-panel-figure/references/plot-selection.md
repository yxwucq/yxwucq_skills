# 科研问题与图型选择

按本格需要读者完成的比较选图。下表是候选图型，可按研究领域和数据结构扩展。优先考虑观测层级、样本量、点的重叠程度，以及整张组图缩到交付尺寸后还能读出的细节。

| 想看什么 | 候选图型与选择依据 |
| --- | --- |
| 分布、尾部和异常值 | 少量独立观测用蜂群图或抖动点图保留每个点。样本充足时可用雨云图同时展示密度、分位数和个体点。比较阈值以下的比例用经验累积分布图（ECDF）；比较多组分布形状可用山脊图，并统一平滑设置。 |
| 组间差异与估计精度 | 多组原始值可用箱线图叠点。比较多个指标或亚组的效应量时，用点区间图或森林图，并标明效应量、参考值和区间含义。只有汇总值时直接展示已有估计及可用区间。 |
| 谁发生了变化 | 同一对象两次测量用配对连线图，比较各组的两个汇总值可用哑铃图。个体配对需有可核对的对象标识。若重点是有多少人改善及改善幅度，可另画个体差值分布并标出零线。 |
| 时间过程与异质性 | 有重复随访时画个体轨迹，按组分面可减轻遮挡。关注整体趋势时画时间点估计与已有不确定性区间。各时间点独立取样时，展示各期分布或组级趋势，连线只表达有依据的对应关系。 |
| 两个连续变量的关系 | 点少时用散点图看离群点与关系形状；点严重重叠时用六边形分箱图或二维直方图呈现局部计数，标明色标。需要辨别边际分布时可配边际直方图。 |
| 多指标模式与样本结构 | 样本 × 特征矩阵可用热图，说明标准化方向、排序及聚类方式。有合适的特征矩阵或已有结果时，可用 PCA 得分图查看主要变异方向，或用已有 UMAP 坐标探索局部邻域。跨条件对照嵌入图时采用同一坐标系。 |
| 组成、集合与流向 | 比较样本组成用百分比堆叠条形图并注明分母；比较某一成分的细小差异用共用基线的点图。多个集合的交集用 UpSet 图。能核对来源、去向和数量时，可用桑基图或冲积图表示流向。 |
| 排名与科研筛选 | 看排序及差距用排序点图或棒棒糖图。已有差异分析结果时，可用火山图展示效应大小与显著性，或用 MA 图检查效应与平均丰度的关系；在方案中写明所用列、变换和阈值来源。 |
| 空间格局与连接关系 | 有实际坐标时可用空间点图、组织切片叠图或分区热图。已有边表时，稀疏关系可用节点连线图，稠密关系可用邻接矩阵。说明位置、颜色、连线或矩阵值各自代表什么。 |

**组图示例。** 对同一批受试者的治疗前后测量，A 格可以用配对连线图展示每个人的走向，B 格用差值 ECDF 读出超过指定改善幅度的比例，C 格在有亚组效应估计及区间时用森林图比较各亚组。若目标改为比较三个中心的个体变化，可让 A–C 都用相同坐标范围的配对连线图，一格一个中心。
