# 科研探索绘图

优先回答当前数据问题，以尽少的图和标注形成可用的第一版。借鉴 KOLF2.1J Perturbation Cell Atlas 的清晰配色、轻量坐标轴和重点提示，沿用项目的视觉语言。

## 工作方式

1. **确定当前要看的问题。** 按数据含义选图。已有明确问题就直接开始；未指定时，先做最有助于判断分布、关系或组间差异的少量视图。不要因为参考论文有某种图就套用它。
2. **先处理项目配置。** 读取 [项目配置约定](references/project-config.md)，查找当前项目已有绘图 TOML；没有时，以 [默认配置](assets/plot_style.toml) 初始化项目根目录的 `plot_style.toml`。两种绘图技能使用同一份项目配置，采用 `explore` profile。
3. **复用项目分析环境。** 使用已有 Python、R 或 notebook 工作流，绘图代码在运行时读取 TOML。除非必要，不为画图重装环境或迁移语言。
4. **先保证数据可信。** 保留真实尺度、类别与缺失值含义。默认展示已提供的结果；不因为画图顺带开展无关统计分析。抽样、聚合、变换、过滤会影响读图时，在图注或回复里说明。探索发现不得写成已经证实的结论。
5. **生成轻量初稿。** 应用 [视觉规范](references/visual-style.md) 的基础规则：白底、稳定的颜色映射、必要坐标轴、无默认网格、少量重点标签。优先单图或少量简单分面，不强制多面板拼版、长图注和显著性星号。
6. **看一遍实际输出。** 检查空图、错轴、标签裁切、颜色错配和明显重叠。修复影响理解的问题即可；除非用户继续要求，不做长时间装饰性迭代。

## 输出与范围

- 默认提供一版可直接查看的图；本地任务可保存 PNG。已有 notebook 中工作时，保留输出和可复现的绘图单元即可，不重复建立整套文件。
- 一两句话说明主要观察、关键限制和适合下一步检查的点。完成绘图不等于完成科学解释。
- 本次修改了配置时，说明所用 TOML 路径及改动内容，特别是新增或改变的组别颜色。
- 用户将初稿用于正式 Markdown 报告、PPT 或论文时，应进入正式成图流程；不要先执行本技能再自动把同一张图完整重做一遍。
- 需要辨认参考风格时，只查看 [素材与证据](references/sources.md) 中与当前图型有关的例子；不必每次加载全部图片。

## 不可被风格覆盖的要求

显式用户要求优先于风格默认值；项目已有颜色含义优先于 KOLF 色板。颜色、点大小和布局可调，数据位置、统计含义和已知组别映射不能为美观而无说明改变。无关任务不创建 TOML，也不修改 Codex 自身配置或全局指示。
