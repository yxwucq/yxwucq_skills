# 决策与沟通

用于分配默认决策权、整理不确定性、提交研究者决定。目标是让研究者集中处理科学取舍，同时保留完整可追溯的方法依据。

## 判断顺序

1. **检查已有决定。** 当前研究计划、明确指示或已经确认的定义能否覆盖此问题？记录其来源与适用范围，避免重复询问。不能把另一项目的决定直接迁移为本项目授权。
2. **确认适用性。** 该惯例是否适用于当前数据层、实验设计、单位和分析目标？依据可来自原始方法论文、官方文档、可靠领域共识或已验证的项目方法。需要查证时优先使用这些来源，不用工具默认值替代科学理由。
3. **自行调查。** 通过文档、数据检查或有限试验可以查明的事实，先查明。将文献支持、数据证据与当前推断区分开；查证受限时保留不确定性，不编造来源。
4. **评估剩余分歧。** 若选项含义等价、性能差异可测且在授权范围内，可自行选择并记录。若合理选项仍代表不同科学问题、实质不同的解释或未解决的方法有效性，提交研究者。

选择简单、通用的实现也要服从科学适用性。研究者可授权探索一组选项，但“替我选一个”不能把不存在的重复、不可识别的效应或未经验证的结果变成有效推断；应说明限制并提出可回答的问题。

## 默认决策记录

每项只记录足以复核的信息，合并相关常规设置：

| 字段 | 内容 |
|---|---|
| 选择 ID / 对应步骤 | 稳定标识，便于图表与配置引用 |
| 采用的做法 | 明确方法、规则或实际值 |
| 采用依据 | 来源、已有决定或检查结果；含必要版本/访问日期 |
| 适用条件 | 为什么适合当前设计；主要失效条件 |
| 参数位置 | 实际执行配置的键或引用 |
| 决策归属 | 通用惯例、证据确定、研究者决定或临时假设 |

不要逐项弹出默认选择；将其放在详细方法记录。正文只摘要影响理解的重要方法。出现不适用、偏离既定规则或实质性异常时突出报告。

## 研究者决策卡

提交前，完成不依赖答复的调查并填写：

- **待决定事项与状态**：准确指出哪个定义未定，避免只给参数名称。
- **为何需要决定**：哪些事实已知，哪些仍不确定，为什么惯例和数据不能唯一确定。
- **合理选项**：通常给 2–3 个真正有区别的选项；选项多时先按科学含义归类。
- **各选项的数值含义**：改变的估计量、背景、比较、样本集合或计算规则。
- **各选项的生物学含义**：分别能回答什么，不能回答什么。
- **证据与代价**：相关来源、已有试验、统计局限、计算开销和下游影响。
- **建议及其条件**：有依据时推荐一个；证据不足时明确没有可靠首选。
- **暂停范围**：哪些步骤依赖此决定，哪些工作可继续。
- **最终决定**：研究者原意、来源/日期和适用范围；收到答复前保持未决。

记录的是可复核的依据、选项、结论和行动，不要求展示模型内部思维过程。

## 情境示例

### 常规实现与科研定义

在已选定、已验证的方法内，调整分块大小以满足内存限制，且验证数值等价，可自行完成。若改用近似算法会改变结果精度或结论，应评估误差并按影响提交选择。

### 背景集合

已有研究方案明确背景集合时按方案执行。若“所有测到的基因”与“所有通过检出筛选的基因”对应不同科学解释且尚未约定，应调查方法要求并提交决策，不能仅因其中一个常见就自动采用。

### 数据中的事实问题

分组字段含义或配对关系不清时先查数据字典、实验记录和元数据。不能从文件名猜出事实后当成已确认设计。仍无法查明时向研究者索取具体事实，指出影响范围。

### 统计信息不足

大量细胞并不自动提供大量独立个体重复。识别到重复结构不足时，先核实设计并说明可支持的描述性结果；不能通过调阈值或重定义独立单位宣称解决统计有效性。

### 暂无答复

对于未定的合并亚群规则，可在已允许的试验预算内比较不同方案并明确标为探索；正式群体定义仍待研究者决定，不能因某个方案得到更显著结果而自动冻结。

## 决定的复用与失效

已确认的决定在同一适用范围内持续有效。新数据或新目标使前提失效时，指出具体变化、受影响步骤和需要重新决定的内容。不要重问未受影响的事项，也不要将全套流程无条件退回起点。
