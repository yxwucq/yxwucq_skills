# 分析定义

用于形成项目分析规格和步骤接口。按研究用途填写适用内容；不适用项简述原因，不强行给描述性分析增加假设检验。已经有明确模板或数据格式时沿用现有约定。

## 研究定义

在设计代码前明确：

| 内容 | 定义要求 |
|---|---|
| 生物学问题 | 具体对象、条件、时间/空间范围，以及希望回答的判断 |
| 研究总体与样本 | 推断希望覆盖谁；实际观测了谁；纳入与排除条件 |
| 单位与重复 | 观察单位、独立实验/生物学重复、配对与嵌套关系 |
| 目标量 | 要估计、描述或预测什么；比较方向、效应单位、参考状态 |
| 输入 | 数据类型、测量层、来源、标识符、元数据与参考资源 |
| 设计因素 | 分组、协变量、批次、混杂与可识别性；适用时的训练/验证划分 |
| 证据用途 | 探索、描述、验证或预测；哪些结论需要额外证据 |
| 成功与限制 | 可检查的成功条件、已知能力边界和不能支持的结论 |
| 资源与产物 | 可用环境、预算、交付物和是否已授权执行全量 |

目标量的示例形式：在指定总体和调整条件下，A 相对于 B 的某测量变化。必须说明这是关联、模型估计、预测还是有设计支持的因果估计，不能从关联输出直接升级解释。

## 步骤定义卡

每个关键步骤使用稳定 ID。较长卡片放入详细方法，流程图仅显示目的、输入输出与依赖。

| 字段 | 定义要求 |
|---|---|
| ID、目的、依赖 | 本步骤解决什么问题，来自哪些步骤，下游如何使用 |
| 输入接口 | 文件/对象、行列含义、类型、标识符键、样本集合、单位与数据层 |
| 数值计算 | 公式或精确算法；聚合顺序、权重、分母、方向和尺度；避免只写工具名 |
| 参考与背景 | 参考状态、背景集合、注释集合、参考基因组或数据库及版本 |
| 数据处理 | 过滤、缺失、零值、重复标识符、极端值、连接和排序规则 |
| 统计定义 | 适用时的模型/假设、比较、独立性、协变量、多重检验族与误差控制 |
| 参数引用 | 指向结构化配置键；区分固定值、适配规则、派生值与临时试验值 |
| 生物学含义 | 输出增减或关系的解释、所依赖假设、不能支持的推断 |
| 输出接口 | 输出对象、行列、单位、数值范围、效应与不确定性（如适用） |
| 诊断和失败 | 数据保留数量、关键分布、检查条件、失败时停止或降级的约定 |
| 实现与代价 | 对应代码/命令与版本、主要规模变量、可缓存中间结果与资源估计 |

数学定义必须与实现一致。例如，均值的比值与比值的均值、先变换后聚合与先聚合后变换不能互相替代而不说明。涉及背景或多重检验时，明确集合如何生成及何时固定。

检查步骤边界，尤其是：

- 原始计数、归一化值、对数值、残差、比例、概率或标准化分数是否被混用。
- 样本/特征连接是否丢失、复制或重排；元数据是否与数值矩阵对应。
- 过滤是否改变目标总体、背景集合或分母；每个阶段保留与排除多少。
- 同一对象是否在选择特征/定义阈值后又被当作独立验证证据。

## 参数规格

分类用于说明职责，同一参数在不同研究中可能具有不同决策等级。

| 类别 | 需要固定或记录的内容 |
|---|---|
| 科学定义 | 目标、比较、背景、样本集合和解释边界；已有决定直接复用 |
| 方法选择 | 方法与关键超参数、候选范围、选择依据和敏感性证据 |
| 数据适配 | 输入统计量、计算公式、适用范围、上下界和超界行为 |
| 执行资源 | 线程、分块、缓存等；允许变化的范围和数值等价要求 |

每个关键参数至少有：配置键、含义、类型/单位、来源、选择或适配规则、允许范围、缺省行为、校验、变更影响。冻结规则，运行时保存解析后的实际值。

数据适配规则还必须说明：

1. 用哪些数据估计参数，估计过程是否包含标签、结局或测试集信息。
2. 在代表性试验与全量数据上如何一致应用；是否会随规模改变科学含义。
3. 稀少样本、空集合、分布异常或超界时停止、报告还是使用有依据的回退。
4. 多个数据集是否各自适配，以及适配后是否仍能直接比较。

避免只填写 `auto` 或“使用默认值”。必须能从已固定规则恢复实际取值。为计算速度改变精度、抽样或近似方法时，说明误差容限与验证依据。

## 文档与配置的一致性

使用现有格式维护唯一执行配置。文档中的表格从配置生成，或引用键和版本。规则需要代码实现时，记录实现位置与内容标识；自然语言定义、实现和示例计算应能互相核对。

不为未知信息制造数值。将未确定项明确标为未决，并关联决策卡；不适用与未确定分别记录。模板填写完整不等于方法已验证。
